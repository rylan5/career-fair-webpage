# Spring Career Fair 2026 Exploration Webpage

This project is a custom HTML and CSS webpage created to document my experience at the Spring Career Fair 2026 at Florida A&M University. The site highlights three companies I spoke with—Epic, Honeywell, and Rocket—and presents key information, unique insights, and personal reflections based on my conversations with their recruiters.

## Project Overview
The webpage includes:
- An introduction explaining the purpose of the site
- Individual company sections for Epic, Honeywell, and Rocket
- Company logos and photos displayed in a structured grid layout
- Descriptions, unique information, and key takeaways for each company
- Direct links to each company’s career page
- A final reflection summarizing what I learned about roles, skills, and opportunities

## Technologies Used
- **HTML5** for page structure and content organization
- **CSS3** for styling, layout, spacing, and color design
- **CSS Grid and Flexbox** for responsive layout and image organization
- **Custom styling** including color themes, spacing, and button hover effects

## Features
- Clean, readable layout with clearly separated company sections
- Grid-based company cards containing images and text
- Consistent color scheme using dark backgrounds and red accents
- Responsive image handling with object-fit and max-height constraints
- Organized file structure with separate folders for CSS and images
- Footer with course and date information

This website was created for my Intro to Web Design course in Spring 2026. It demonstrates:
